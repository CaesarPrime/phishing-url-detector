About this Prototype

This is a browser prototype of the Intelligent Hybrid Phishing Uniform Resource Locator Detection System Using Machine Learning and Cybersecurity Rules.

  • It extracts the same eleven lexical URL features as the full system.
  • It applies the same six weighted cybersecurity rules and risk levels.
  • It adds a lexical risk estimate for the score shown as "model estimate".
Prototype note: the trained XGBoost model runs in the full Python/Flask application (see the GitHub repository). In this webpage prototype, accounts and scan history are stored only in this browser.
